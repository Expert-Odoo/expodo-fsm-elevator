# Elevator & Lift Field Service

Field service for elevator and lift maintenance companies, built on Expodo Field Service.

Log each unit, its type, capacity and floors served, follow the job from install or
breakdown to invoice, track periodic regulatory inspections with due dates and
certificate references, and run the safety checks the job needs.

Free, LGPL-3, for Odoo Community 17, 18, 19 and 20.
